# Security policy

`git lopper` removes folders, so a bug that makes it remove the wrong worktree is a
security issue too.

## Supported versions

Only the latest release gets fixes.

## Report a vulnerability

Do not open a public issue. Use
[Report a vulnerability](https://github.com/albertovincenzi/git-lopper/security/advisories/new)
(GitHub private vulnerability reporting). Give the version (`git lopper -V`), your OS,
your git version, and the steps that show the problem.
